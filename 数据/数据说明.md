# 数据说明

所有误差单位：MAPE 为 %，MAE 为 W（功率）或 mm/s（速度），差值为百分点。
模型代号：EWT = 自适应 EWT；NAT_b = 固定边界 b kHz（EWT 原生滤波器形状）；MEYd_b = 固定边界 b kHz、过渡带半宽 d kHz；
FIX5BW = 已有 5 带 Butterworth；RAW = 不分带；TRAIN_MEDIAN = 训练中位数基线。窗口：EARLY = 起点后 2–10 ms，LATE = 6–14 ms。

| 文件 | 内容 | 主要列 |
|---|---|---|
| predictions.csv.gz | **原始预测**：49 种模型 × 2 窗口 × 3 种子 × 46 组 × 2 目标，每行一个外层折的留出预测 | window, seed, fold, condition, model, target, sample_id, observed, predicted, AE, APE |
| selections.csv | 每个外层折 SFS 选出的特征（分号分隔） | window, seed, fold, model, target, selected |
| metrics_per_seed.csv | 每个种子的误差 | window, seed, model, target, macro_MAE, macro_MAPE, group_MAE, group_MAPE |
| mean_metrics.csv | **主结果**：3 个种子平均，含种子间最小/最大 | ...，macro_MAPE_seed_min, macro_MAPE_seed_max |
| ensemble_metrics.csv | 3 个种子先平均预测再算误差（最终提交口径） | window, model, target, macro_*, group_* |
| condition_errors.csv | 每个留出工况的平均 APE（3 种子平均），配对检验的输入 | window, target, model, condition, APE |
| paired_comparisons.csv | 配对比较：均值差、95%/90% bootstrap 置信区间、Wilcoxon p、优/劣/平工况数、±1 个百分点等效判断 | new, baseline, mean_delta_pp, ci95_*, ci90_*, wilcoxon_p, equivalent_pm1pp |
| noise_reference.csv | 噪声参照：种子间范围中位数；边界在 54.5–56.5 kHz 内移动的标准差与范围 | median_seed_range_pp, local_grid_sd_pp, local_grid_range_pp |
| selection_frequency.csv | 关键模型的选特征频率（42 次外层拟合） | window, model, target, feature, count, total, percent |
| separability.csv | 不训练模型的单特征区分度 ω²，边界 20–75 kHz（0.5 kHz 步长） | window, shape, boundary_khz, feature, omega2_condition, omega2_speed, omega2_power_given_speed |
| valley_by_sample.csv | 49 个样本的谱谷中心和谷深（激光开启段、衰减尾巴），以及参数和板上行列 | sample_id, power_W, speed_mm_s, row, col, valley_plateau_khz, depth_plateau_db, valley_tail_khz, depth_tail_db |
| valley_summary.json | 谱谷统计汇总：均值、范围、与功率/速度/位置/打印顺序的 Spearman 相关、空闲噪声检查 | — |
| valley_spectra.npz | 每个样本的归一化功率谱（开启段、尾巴）和空闲噪声谱，用于画图 2 | f, ids, plateau, tail, idle |
| unknown_per_seed.csv | 未知样本 #41/#43/#49 在各分带下每个种子的预测 | sample_id, model, target, seed, predicted |
| unknown_summary.csv | 未知样本预测汇总（3 种子平均、最小、最大），含同学的 Linux 存档 EWT 作对照 | sample_id, target, model, mean, min, max |
| unknown_selections.csv | 未知样本最终模型选出的特征 | model, target, seed, selected |
| archived_reference.csv | 同学包中原有的存档结果（Linux），仅供对照 | source, window, model, target, macro_MAPE, group_MAPE, macro_MAE |
